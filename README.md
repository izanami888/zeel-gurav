# Тоглоомын Тавцан

Монгол хэл дээрх онлайн ширээний/бодлогын тоглоомын вэбсайт ([playboard.gg](https://playboard.gg)-с санаа авсан). Next.js (App Router) + TypeScript + Tailwind CSS дээр бүтээгдсэн.

## Локал ажиллуулах

```bash
npm install
npm run dev
```

Дараа нь [http://localhost:3000](http://localhost:3000) хаягаар нээнэ.

## Supabase тохиргоо

Ирээдүйн онлайн олон тоглогч (playroom) болон зарын систем нь [Supabase](https://supabase.com) ашиглана (үнэгүй tier дээр ажиллана).

1. [supabase.com](https://supabase.com)-д шинэ төсөл үүсгэнэ.
2. `.env.example`-г хуулж `.env.local` нэрээр хадгална:
   ```bash
   cp .env.example .env.local
   ```
3. Project Settings → API хэсгээс `Project URL` болон `anon public` key-г аваад `.env.local`-д бичнэ:
   ```
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
   ```
4. Зарын хүснэгтийг үүсгэхийн тулд `supabase/migrations/0001_ads.sql`-г Supabase SQL Editor дээр ажиллуулна (эсвэл Supabase CLI ашиглаж болно: `supabase db push`).
5. Онлайн шатрын өрөөний хүснэгтийг үүсгэхийн тулд `supabase/migrations/0002_chess_rooms.sql`-г мөн адил ажиллуулна.
   "Чулуу таалцах"-ын онлайн өрөөнд `supabase/migrations/0003_chuluu_rooms.sql`-г ажиллуулна.
   "Морь уралдуулах"-ын онлайн өрөөнд `supabase/migrations/0004_mori_rooms.sql`-г ажиллуулна.
6. Онлайн шатарт сервер талын түлхүүр хэрэгтэй. Project Settings → API хэсгээс `service_role` (secret) key-г аваад `.env.local`-д (Vercel дээр бол Environment Variables-д) нэмнэ. Энэ түлхүүрийг хэзээ ч `NEXT_PUBLIC_` угтвартай болгож болохгүй:
   ```
   SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
   ```

### Онлайн шатар хэрхэн ажилладаг вэ

- Тоглогч бүр `localStorage`-д хадгалагдсан нэргүй ID-тай (нэвтрэх шаардлагагүй). Хүснэгтэд зөвхөн ID-ийн SHA-256 hash хадгалагдана.
- Хөтөч `chess_rooms` хүснэгтийг зөвхөн **унших** эрхтэй (RLS). Өрөө үүсгэх, орох, нүүх, бууж өгөх, тэнцээ санал болгох бүх бичилт `app/api/chess/rooms` API route-оор дамжина. Тэнд тоглогчийн ID, ээлж болон нүүдлийг chess.js-ээр шалгаад дараа нь хадгална.
- "Чулуу таалцах" онлайн горим мөн адил аргаар ажиллана. Тоглогчдын атгасан чулууны тоо тусдаа `chuluu_hands` хүснэгтэд хадгалагдана — хөтөч түүнийг унших эрхгүй (RLS, policy байхгүй), Realtime-д ч ороогүй. Бүгд таасны дараа л сервер тоонуудыг нийтийн `chuluu_rooms` мөрөнд бичнэ. Удаан чимээгүй болсон тоглогчийн ээлжийг сервер алгасна.
- "Морь уралдуулах" онлайн горимд шагайг **сервер** хаяна. Хөтөч зөвхөн "хая" гэсэн хүсэлт илгээх бөгөөд `app/api/mori/rooms` нь ээлжийг шалгаж, шагайг санамсаргүйгээр хаяж, морийг нүүлгээд `mori_rooms` мөрөнд хадгална. Бүх хөтөч тэр мөрийн сүүлийн хаялтаас (`last_roll`) ижил хөдөлгөөн тоглуулна. Удаан чимээгүй болсон тоглогчийн өмнөөс сервер хаяна.
- Өөрчлөлт Supabase Realtime-аар (Postgres Changes) бусад төхөөрөмжид очно; хэн холбогдсон байгааг Presence харуулна. Realtime тасарсан үед хэдэн секунд тутам шууд уншдаг нөөц горимтой.

> **Тэмдэглэл:** Supabase тохируулаагүй үед сайт хэвийн ажиллана — зарын байршилд зөвхөн placeholder ("house ad") харагдаж, тоглоомуудын "Онлайн тоглох" сонголт нуугдана.

## Одоогийн байдал

- ✅ Нүүр хуудас, тоглоомын карт grid, зарын banner слот
- ✅ Хөндлөвч тоглоом (Tic-Tac-Toe) — локал 2 тоглогчийн горим, ялалт/тэнцлэлт илрүүлэлт
- ✅ Тоглоом дууссаны дараах үр дүнгийн дэлгэц + 1080x1920 (Instagram Story хэмжээтэй) хуваалцах зураг үүсгэгч (`next/og` ашигласан, `/api/result-image` эндпойнт)
- ✅ Зарын систем: Supabase `ads` хүснэгт (SQL migration), `<AdBanner />` компонент, impressions/clicks тооллого
- ✅ Шатар — локал 2 тоглогч, компьютертэй (Stockfish), онлайн (өрөө + QR код/холбоос, үзэгч, бууж өгөх, тэнцээ санал болгох)
- ✅ Чулуу таалцах — 2–6 тоглогч нэг төхөөрөмж дээр (утсаа дамжуулж), эсвэл 1–5 компьютертэй, эсвэл онлайн (2–6 тоглогч, өрөө + QR код/холбоос)
- ✅ Морь уралдуулах — шагайгаар тоглодог морин уралдаан: 2–6 тоглогч нэг төхөөрөмж дээр, эсвэл 1–5 компьютертэй, эсвэл онлайн (2–6 тоглогч, өрөө + QR код/холбоос, үзэгч; шагайг сервер хаяна); 12/20/30 шагайн зам, "Түлхэх дүрэм" сонголттой
- ✅ Supabase клиент (`lib/supabase.ts`), онлайн өрөөний Realtime код (`lib/realtime.ts`), сервер талын өрөөний логик (`lib/chessRooms.ts`)
- 🚧 Онлайн олон тоглогчийн горим (`/games/tic-tac-toe/room/[roomId]`) — зөвхөн "Тун удахгүй" placeholder, бодит логик хийгдээгүй

## Төслийн бүтэц

```
app/                    # App Router маршрутууд (хуудас бүр)
  api/result-image/     # Хуваалцах PNG зураг үүсгэгч (edge route, next/og)
  games/tic-tac-toe/    # Тоглоомын хуудас + онлайн өрөөний placeholder
components/             # Дахин ашиглагдах UI компонентууд
  games/                # Тоглоом тус бүрийн UI
lib/                    # Supabase клиент, ads, realtime, resultImage helper-ууд
games/                  # Тоглоом тус бүрийн цэвэр логик (UI-гүй)
supabase/migrations/    # SQL migration файлууд
```

## Дараагийн алхмууд

1. **Хөндлөвч тоглоомын онлайн горим** — шатрын онлайн өрөөтэй ижил аргаар (`lib/realtime.ts`, `lib/chessRooms.ts`-г жишээ болгон) хэрэгжүүлэх.
2. **Илүү олон тоглоом нэмэх** — Шашки (checkers), Дөрөв дараалуулах (Connect Four). `lib/games.ts`-д метадата нэмээд `/games/<id>` дор шинэ маршрут үүсгэхэд л хангалттай.
3. **Зарын admin хуудас** — `/admin/ads` дор зар нэмэх/засах/идэвхжүүлэх, статистик (impressions/clicks) харах энгийн удирдлагын интерфэйс (`lib/ads.ts` доторх TODO-г үзнэ үү).
4. **Үр дүнгийн зургийн дизайныг сайжруулах** — Илүү олон загвар, тоглоом бүрт өөр өнгө палитр, тоглогчийн avatar/нэр гэх мэт.
